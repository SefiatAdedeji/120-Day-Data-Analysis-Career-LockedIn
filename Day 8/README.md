# Day 8 - Guided Excel Project (Sales Performance Dashboard)

**Task:** Work on a guided Excel project and build a Sales Performance Dashboard.

---

## Overview  

Today, I worked on a Sales Performance Dashboard using Excel.

The goal of this project is to analyze sales data, calculate key performance indicators (KPIs), and build a structured foundation before designing the final dashboard.

This project focuses on applying Excel not just for analysis, but for data modeling and structured reporting.

---

## Steps Completed  

### 1. Data Cleaning  

- Reviewed the dataset for inconsistencies  
- Removed unwanted and irrelevant columns  
- Checked for missing values  
- Ensured proper data types  

This ensured the dataset was analysis-ready before building metrics.

---

### 2. KPI Creation Using Pivot Tables  

I used Pivot Tables to calculate core sales KPIs such as:

- Total Revenue  
- Total Quantity Sold  
- Average Discount  
- Total Quantity  
- Total Profit generated  

Pivot Tables helped summarize large volumes of data efficiently.

---

### 3. Writing DAX in Excel (New Skill Applied)  

For the first time, I wrote DAX measures directly in Excel using the Data Model.

This allowed me to:

- Create more dynamic KPI calculations  
- Build structured measures instead of relying only on Pivot logic  
- Improve flexibility for dashboard expansion  

---

### 4. Calendar Table Creation  

I created a Calendar Table using the Data Model in Excel to enable:

- Time-based analysis (Year, Month, Quarter)  
- Proper date relationships  
- Scalable time intelligence  

This is an important step for building professional dashboards.
